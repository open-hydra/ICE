Everything you need for condensed-phase simulation

A complete Eulerian particle solver written in modern Fortran

Three Kinetic Closures

Monokinetic, isotropic Gaussian and anisotropic Gaussian. The Gaussian closures carry a velocity dispersion, so crossing streams are represented.

Cell-Centred Finite Volume

Conservative discretisation on multi-block structured hexahedral grids, with MUSCL reconstruction. Block connections, periodicity and chimera overset.

Evaporation & Drag & Heat Transfer

Several models for evaporation, drag, and Nusselt correlations, from creeping flow to the compressible fits, plus grey-body radiation.

Explicit Time Marching

Forward Euler, SSP-RK2 and SSP-RK3, with CFL-based step control. Global and local time-stepping, residual smoothing and grid sequencing for steady state.

Parallel Execution

OpenMP over cells and MPI over blocks, separately or together.

Flexible I/O

Tecplot and VTK I/O, temperature-dependent material property tables, point probes for time histories, and restart from any written solution.

Up and running in minutes

One install script fetches the submodules, configures CMake and compiles the Fortran core. The shipped test cases are complete and each checks its own result.

Installation guide → Quick start
terminal 
# Clone and build
$ git clone https://github.com/open-hydra/ICE.git
$ cd ICE && ./install.sh build --compilers=gnu --use-openmp

# Run one of the shipped cases and check it
$ cd test/Doisneau/IG
$ ./ICE.sh -p 4 solve && python3 verify.py
