Everything you need for condensed-phase simulation

A complete Eulerian particle solver written in modern Fortran

Eulerian Condensed Phase

Eulerian description of dispersed particles using the monokinetic (MK) closure. Supports mono- and poly-disperse size distributions organised in groups.

Cell-Centred Finite Volume

Conservative finite-volume discretisation on multi-block structured hexahedral grids with high-order flux reconstruction.

Heat & Mass Transfer

Convective heat exchange between particle and gas phases via Nusselt correlations (Stokes, Ranz–Marshall). Latent heat and phase-change modelling.

Explicit Time Marching

Multi-stage Runge–Kutta time integration with CFL-based time-step control. Local and global time stepping for steady-state and time-accurate runs.

Parallel Execution

Shared-memory parallelism via OpenMP and distributed-memory MPI with ghost-cell exchange across block boundaries on HPC clusters.

Flexible I/O

Tecplot (ASCII & binary) and VTK output via ORION. Point probes for time histories and full restart capability.

Up and running in minutes

ICE ships with a single install script that handles all dependencies, compiles the Fortran core, and puts the binary on your PATH.

Installation guide → Quick start
terminal 
# Clone and build
$ git clone https://github.com/open-hydra/ICE.git
$ cd ICE && ./install.sh build --compilers=gnu

# Run a simulation
$ cd test/mono-disperse
$ ./ICE.sh solve
